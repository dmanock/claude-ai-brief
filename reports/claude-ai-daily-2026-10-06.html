Claude for Government Is Generally Available

Anthropic made Claude for Government generally available on September 30 for federal and state agencies. It carries FedRAMP High authorization, the bar many agencies need before touching sensitive workloads.

That clears a major procurement hurdle for public-sector buyers.

Research

Claude Agents Discover a Novel Enzyme System

Anthropic's new life sciences lab says about 950 Claude agents searched a DNA sequence database for 21 hours, using 210 million tokens. They narrowed 200,000+ reverse transcriptases to 3,500 and then to 20 top candidates.

The result is a CRISPR-like system called array-associated reverse transcriptases. MIT's Feng Zhang called it an exciting example of agents contributing to biological discovery. Its exact function is still unknown.

Claude Code

Claude Code 2.1.289 Fixes Freezes and Auth Annoyances

Version 2.1.289 landed October 3. It fixes terminal freezes with nested script tags, improves plugin loading and repairs permission rules for symlinked files. It also reverts an authentication change that had been signing people out more often.

Version 2.1.288 added a --max-findings option for code reviews and re-authentication when MCP servers ask for extra OAuth scope.

Enterprise

Meta and Microsoft Steer Staff Away From Claude

Per a report relayed October 5, Meta cut Claude Code users from 60,000 to 30,000 employees and is pushing its own Muse Code and MetaCode. Microsoft is trimming expected Anthropic spend by a third from about $1 billion and nudging staff to GitHub Copilot.

Anthropic still reaches 43.5% of US businesses paying for subscriptions or tokens as of July. Budgeting is the real pain: only 11% of surveyed firms can accurately forecast AI spend.

Big Tech Wants Its Own Stack. Everyone Else Wants What Ships.

Meta and Microsoft are rivals with their own coding tools, so pulling back on Claude is partly competitive instinct. The broader market tells a different story, with 43.5% of US businesses paying Anthropic.

Meanwhile FedRAMP High opens government doors and the enzyme result shows agents doing real science. Anthropic is trading a few hyperscaler seats for regulated and research work.
