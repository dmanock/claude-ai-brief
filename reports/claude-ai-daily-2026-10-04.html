Barclays Widens Its Claude Rollout

Barclays is expanding its use of Claude to modernize legacy systems and improve operational efficiency, Bloomberg reported October 1. Coverage points to roughly 16,000 employees and a goal of getting about half the bank’s developers on Claude by year end.

Anthropic also listed the news on its newsroom the same day. Banks move slowly, so a rollout this size is a real signal.

Sonnet 5.5 Is Faster and Cheaper, With Haiku 5.5 on the Way

Sonnet 5.5 runs more than 30% faster and costs up to 30% less for most work, at $2 per million input tokens and $10 per million output. It scored 70.6% on Terminal-Bench 4.0, ahead of Opus 5.5 on that agentic coding test.

Artificial Analysis puts it at 56 on its Intelligence Index, two points behind Opus 5.5. Haiku 5.5 is expected soon for high-volume work.

Claude Code

Claude Code Mods Let You Rewrite the Agent

Anthropic introduced mods on October 1: customizable TypeScript functions that can rewrite a prompt before it reaches the model, add UI elements, and replace built-in features. They run in both the CLI and desktop.

Power move for teams that want one tool to behave their way. Also a reminder to review any mod before you install it.

Claude Code

Claude Code 2.1.289 Tightens Permissions and Plugins

The October 3 release fixes permission rules not holding over nested shell commands and user-installed mods on managed machines, and read deny rules now apply to @-mentioned and symlinked files.

It also adds agent.spawn for teammates, fixes stale plugin copies from local installs, and repairs plugin hot reload for symlinked --plugin-dir.

Ecosystem

Plugin Directory Portal Opens to Third-Party Developers

A new portal, launched September 25, lets outside developers submit plugins with auto-validation, review tracking and usage analytics. It supports MCP 2.0 and Enterprise Managed Auth.

Pair it with the 2,000+ item Claude Marketplace and the distribution story for plugin builders gets a lot clearer.

Two Recent Incidents, Both Resolved

A September 29 outage hit claude.ai, Claude Code and the API from 14:00 to 14:59 UTC, with sign-in failures and errors starting new chats. On October 1, delays applying purchased credits caused some requests to fail until 22:36 UTC.

Status shows all systems operational now.
