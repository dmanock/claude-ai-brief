📢 Official Updates
Launch

MCP Servers Can Now Ship Skills, Run Tasks and Ask Questions

Anthropic says MCP servers can now deliver Skills straight into Claude and Claude Code. Skills over MCP is in public beta, on by default for Pro, Max and Ultra, available on Team once an admin turns it on, and coming soon to Enterprise. Shopify, HubSpot and Atlassian are live, with Carta coming soon.

Two more MCP features are now generally available on the same plans and rolling out to Team and Enterprise: Tasks for long-running jobs (ZoomInfo is the example) and Elicitation, which lets a server ask you for input mid-flow (Supabase, Railway, GitHub). File Uploads is "rolling out soon." Anthropic cites 700M+ monthly MCP SDK downloads and 10,000+ connectors for Claude.

Beta

Claude Artifacts Can Now Install as Desktop Apps

A new beta lets you install an artifact as an app on Mac or Windows, with its own window and icon. No packaging, code signing or separate API key needed, per reports on the launch.

Installed apps can send notifications, add menu bar or tray icons and listen for global shortcuts. Permissions come in three tiers (default, app-specific and full computer access) and must be re-granted after each app update. It's rolling out gradually to paid subscribers.

Product

Monthly Recap Exits Beta, File Sharing With Connected Apps Arrives

Monthly recap is now out of beta on Free, Pro, Max and Ultra across web, desktop, iOS and Android. Recaps can now pull in Claude Code sessions and cloud Cowork tasks, and you can delete stored recaps.

Also new in beta: sending files to connected apps and saving files from them. It's rolling out gradually on Pro, Max and Ultra, and on Team and Enterprise once an owner enables it.

Claude Code

Claude Code 2.1.332 Pulls Skills From MCP Servers

Version 2.1.332 shipped early Nov. 25 and is the Claude Code side of today's MCP news: skills from MCP servers (beta) now show up in the / menu as server:skill. There's also a new PreSkillShellCommand hook event and an OpenTelemetry assistant_response event for response logging.

Other adds: an "Always deliver" option for held messages from other sessions, and the Cyber Verification Program access tier in the startup header. Fixes cover freezes with large hook output, claude auth login exit status and several Code Mode issues.

Claude Opus 4.5 Retires From the API on Jan. 22

Anthropic's developer release notes set a retirement date for claude-opus-4-5-20251101: Jan. 22, 2027. The recommended replacement is Claude Opus 5.5.

If you still pin Opus 4.5 in production, that's under two months to migrate and re-run your evals. The same notes add beta webhook events, external_storage.failed and external_storage.recovered, for the zero-retention safeguards setup covered yesterday.

Markets

ANT Closes Below Its $83 IPO Price for the First Time

In its fourth session, ANT fell 6.5% to $81.91 Tuesday, its first close under the $83 offer price. It traded as low as about $75.61 before bouncing, on roughly 311M shares, as Nvidia gave back some of Monday's surge and the Nasdaq slid 1.4%.

The missing floor: Morgan Stanley exercised its full 147M-share greenshoe at $83 and closed its stabilization position after one day, per Reuters via TechTimes. So no underwriter bid is defending the IPO price. Markets are closed Thursday for Thanksgiving.

🧠 Analysis
Platform

MCP Is Becoming Claude's App Store

Put this week's launches side by side. MCP servers now ship Skills, run Tasks and ask questions. Artifacts install as real desktop apps. Files move between Claude and connected apps. That's distribution, not just plumbing.

The play: vendors like Shopify and HubSpot package their know-how as Skills, and you build your own small tools as artifacts. Claude becomes the place both live. If you maintain an MCP server, shipping Skills with it just became the obvious next step.

Take

The Greenshoe Hangover

ANT priced above its range, popped 34% on day one, and gave it all back in four sessions. The stock didn't change. The support did. With the stabilization bid gone, $83 is just a number.

Coverage is bullish and index buyers are lined up, but so are the unlocks. Expect choppy trading into December. The product cadence, meanwhile, hasn't slowed one bit.
