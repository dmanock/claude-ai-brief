📢 Official Updates
Program

Anthropic Launches a $100M Academy for Frontier Deployed Engineers

Anthropic announced the Claude Frontier Academy on October 2, committing $100 million to develop 10,000 Frontier Deployed Engineers by the end of 2027. The model borrows from medical training: a 4-day intensive building a Claude system for a simulated enterprise, then a 12-week residency leading a real deployment.

It is in early access with select customers and partners, and first credentials are expected in early 2027. Pricing has not been disclosed.

Government

Claude for Government Is Now Generally Available

The FedRAMP High authorized platform went GA on September 30 for federal and state agencies. It comes with governance controls built for the public sector.

Pricing is usage-based with spend caps and no seat fees, which makes it easy to start small.

Claude Code

Claude Code 2.1.288 Is All About Reliability

The October 2 release continues from partial output after mid-response API timeouts, and long conversations stop failing with “Prompt is too long” thanks to better auto-compact. --resume no longer drops files and context during compaction.

MCP tool calls no longer run twice on large results, Cowork sessions stuck in a waiting state are fixed, and screen reader mode got several improvements.

API

Sonnet 4.5 Gets a Retirement Date: November 30

The Claude Developer Platform deprecated Claude Sonnet 4.5 on September 30, with retirement set for November 30, 2026. Anthropic recommends migrating to claude-sonnet-5-5.

Remember the thinking setting changes when you move over, so test before the deadline rather than on it.

Ecosystem

Claude Marketplace Brings 2,000+ Connectors and Plugins

Anthropic’s Claude Marketplace, reported September 27, collects more than 2,000 connectors and plugins from Atlassian, Google, Microsoft, Notion and Salesforce. Partner agents from CrowdStrike and Snowflake sit alongside them.

Developers can build their own with MCP and Agent Skills, and Accenture and Deloitte offer consulting help.

Take

The Bottleneck Isn’t the Model. It’s the People Who Deploy It.

A $100M academy, a government platform and a 2,000-plugin marketplace tell one story: Anthropic is building the layer around the model. Models are shipping faster than companies can absorb them.

Training deployment engineers is a bet that enterprise adoption stalls on skills, not capability. If it works, it also builds a loyal army of Claude-certified builders.
