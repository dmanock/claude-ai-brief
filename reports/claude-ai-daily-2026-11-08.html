Security

"Don't Ask Again" File Exposes Secrets in 1,122 Public Repos

Per The Hacker News, Apiiro found that choosing "Yes, and don't ask again" in Claude Code saves the approved command to .claude/settings.local.json. If that command contained a password or key, it sits in the file in plain text. Researchers counted 1,122 public copies on GitHub.

The advice: rotate any exposed secrets first. Deleting the file does not remove it from git history.

Security

Malicious Extension Could Drive Claude Dispatch

The Hacker News reports Forever Security showed an extension running on claude.ai could send Dispatch instructions to Claude Desktop and run code on a user's computer. Anthropic reportedly said Dispatch would be retired, with a target of end of October.

🧠 Analysis
Take

Convenience Settings Are Attack Surface

Both security stories share a theme. A shortcut meant to cut friction became the path in. One saves secrets to disk, the other trusts a message from the browser.

If you use agents daily, audit your local config, gitignore settings.local.json, and keep secrets out of commands. Boring, fast, effective. A Hacker News essay this week also warned that AI-found vulnerabilities are about to flood defenders. Expect more of this, not less.
