📢 Official Updates
Product

Claude Duet Opens as a Research Preview

Anthropic’s new Duet app is a proactive agent for professionals and small businesses. It builds daily briefings and dashboards, suggests actions, and finishes tasks in the background on its own virtual machine, then checks back when it needs approval. It runs on Claude Opus 5.5.

Access is a waitlist for Pro and Max subscribers on iOS, Android and the web. It can buy things through Stripe’s Link or Shopify’s Shop Pay, with payments gated on user approval. It won’t trade securities or move money, and a new classifier screens for leaked sensitive data.

Agent Skills Standard Donated to the Linux Foundation

A third-party roundup of Anthropic’s news index says Anthropic donated the Agent Skills standard to the Agentic AI Foundation, which sits under the Linux Foundation. The name, logo, GitHub organization and the agentskills.io domain transferred with it.

The summary comes from a secondary source, so check Anthropic’s own pages for governance details.

Platform

Admin Controls Land: Web Fetch Toggle, Claude Tag API, Inference Hooks GA

The Claude Platform release notes for Oct 20 add an admin switch to turn web fetch off, plus allowed and blocked domain lists. Managed Agents web fetch and web search now obey those org-level rules as well as the agent’s own lists.

The Claude Tag API is in beta for Enterprise to manage Slack channel settings, and inference hooks are out of beta for Enterprise orgs.

Market

Anthropic’s Public IPO Filing Is Reportedly Close

Sources told Yahoo Finance that Anthropic could publicly file its S-1 as soon as Friday, a step toward a possible November listing. Reports put Q3 revenue at $16.8 billion, up from $11.5 billion in Q2, with a raise of up to $100 billion at roughly $2 trillion discussed.

Anthropic has not confirmed timing, and listing remains subject to market conditions. We did not find a confirmed filing at press time.

Competition

Duet Enters a Crowded Proactive-Agent Field

TechTarget notes the rivals: OpenAI’s Dots in September, Google’s Gemini Agent on October 8, and Meta’s Muse. Forrester’s William McKeon-White says Duet’s standout trait is the restraint of its rollout.

GAI Insights’ Paul Baier doubts large enterprises will deploy any of them soon.

🧠 Analysis
Take

Neutral Standards, Gated Agents

Two moves, one strategy. Giving Agent Skills to the Linux Foundation makes the format hard for anyone to fight. Launching Duet by waitlist with approval gates makes the product hard to fear.

Anthropic is trading speed for trust, right as it heads toward public markets. If the S-1 lands, expect the risk-factor section to say a lot about how it weighs the two.
