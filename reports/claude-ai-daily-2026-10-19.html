📢 Official Updates
Announcement

Anthropic Launches a Public Benefit Fund

Anthropic says it will commit 5% of its shares to a new Anthropic Public Benefit Fund, subject to stockholder approval. The board can add 2% more for every 50% rise in company value above a baseline it has not disclosed.

With earlier pledges, including the co-founders' and an employee equity donation match, about 20% of shares are headed to public good. The Fund is a wholly owned LLC, and Anthropic says none of its equity goes to lobbying or political giving.

💻 Developer & API
Claude Code

Claude Code 2.1.299 Stops Sending Gateway Keys

Per Mixed News, Claude Code sent the API key set for a third-party gateway to Anthropic on five routine request types when ANTHROPIC_BASE_URL pointed at a proxy. A sixth path hit managed-settings setups. Version 2.1.299 stops it.

Anthropic has published no CVE or severity rating, and the changelog does not say whether keys were logged. If you route through a gateway, update and consider rotating the key.

🧠 Analysis
Take

Giving Away Equity Before the IPO

Pledging a slice of the company to public good right before a reported IPO is a statement. It shapes how investors, regulators and critics read Anthropic's public benefit structure. The structure is an LLC, not a charity, which keeps Anthropic in control of how the money moves.

Musk's reply shows how fast a governance story becomes a social media story. The details Anthropic promised in the coming months are what matter.
