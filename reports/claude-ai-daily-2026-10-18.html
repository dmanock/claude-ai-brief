📢 Official Updates
Product

Code Review Is Now Generally Available

Code Review is out of research preview for Team and Enterprise plans. Reviews are roughly three times faster, with most finishing in 6 to 10 minutes instead of about 20.

Admins can set Quick, Standard (default) or Deep per repository. Eligible Enterprise organizations can claim at least $10,000 in Code Review credits by January 15, 2027.

Standalone Claude Design Closes December 14

Claude Code 2.1.302 includes a notice that standalone Claude Design closes on December 14, 2026. The notice appears in release notes tracked by Releasebot; we found no separate Anthropic post explaining the plan.

If you have designs in there, plan your export before the date.

💻 Developer & API
API

Opus 5.5 Fast Mode Exits Preview

Fast mode for Claude Opus 5.5 no longer needs an access request, and it is now available on Azure-hosted Claude in Microsoft Foundry. Fast mode for Opus 5 and Opus 4.8 stays in preview and still needs the beta header.

The Compliance API also gains a beta endpoint that returns the instructions Claude Enterprise org members have saved for Claude.

Claude Code

Claude Code 2.1.300 to 2.1.302

Version 2.1.300 adds mod prompt controls and /advisor on Claude Platform on AWS. Version 2.1.301 adds Vim % bracket matching and LaTeX rendering in VS Code, and fixes the fable alias to fall back to the previous Fable model.

Version 2.1.302 adds CLAUDE_CODE_AUTO_MODE_MODEL, an idle compaction row in /config, and turns fork subagents on by default in claude -p, the Agent SDK, desktop and VS Code.
