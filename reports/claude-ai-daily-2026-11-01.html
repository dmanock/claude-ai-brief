📢 Official Updates
Policy

Anthropic Confirms a Claude Code Rule Against Cloning Games

Users spotted a new rule in Claude Code around Oct. 27: “Do not build a recreation of a specific existing game, even if it is renamed or called original.” An Anthropic staffer, Addy Osmani, confirmed that two sentences were added to Claude Code's prompt for Opus 5.5, because using Claude to infringe IP violates the usage policy.

He says original games, genre games and games built from a developer's own designs and assets should keep working, and that Anthropic will keep refining the balance.

IPO

IPO Roadshow Could Start the Week of Nov. 9

Per Bloomberg, as cited by XTB, the roadshow could begin the week of Nov. 9 at the earliest, with a debut targeted before Thanksgiving on Nov. 26. The Oct. 26 S-1 lists the ticker ANT on the Nasdaq Global Select Market, with Goldman Sachs and Morgan Stanley as underwriters.

H1 2026 revenue was $16.29B against $1.16B a year earlier, with a $693M operating loss and an $80.75B net loss. The gap between those two loss figures is not explained in the coverage. No price range or offering size is official yet.

Claude Code

Opus 4.8 Fast Mode Gets a Shutoff Date

Fast mode for Opus 4.8 was deprecated as of Oct. 30 and is removed Nov. 30 in Claude Code 2.1.316. After that, requests return an error instead of falling back to standard Opus 4.8. Anthropic recommends moving to Opus 5.5 to keep the speedup.

2.1.316 also adds CLAUDE_CODE_DISABLE_ULTRATHINK and CLAUDE_CODE_SUBAGENT_EFFORT environment variables.

Security

New Write Guardrail and a Telemetry Rollback

2.1.314 added permissions.blockWritesOutsideWorkingDirectories, so Write, Edit and NotebookEdit refuse paths outside the working directories in every permission mode. 2.1.312 fixed --restricted sessions uploading files from outside those directories when a Read allow rule covered them.

The claude_code.safety_event OpenTelemetry event from 2.1.307 was withdrawn in 2.1.312 after about a week, so dashboards built on it need rework. Idle compaction also reached VS Code and the Desktop Code tab.

API

Usage and Cost Analytics API Lands in Beta

On Oct. 29 Anthropic launched a beta Usage and Cost Analytics API for organization token usage and cost, filterable by model, workspace, API key and requester. The older Usage and Cost endpoints are now legacy but still supported.

On Oct. 28 the maximum request size for the Messages and Token Counting APIs rose from 32 MB to 128 MB on the first-party Claude API.

🌎 Community & Ecosystem
Backlash

Devs Say the Guardrails Catch More Than Clones

Tom's Hardware reports users claiming Claude Code or Opus 5.5 refuses innocuous reverse-engineering, such as analyzing a Windows crash dump or clearing junkware from a Samsung TV. Some game devs say Claude blocked anti-cheat work and security reviews for their own games.

Anthropic has not commented on the reverse-engineering claims, and a commenter disputes the framing. The article suggests a link to the Oct. 6 Cyber Verification Program, but calls that unconfirmed.

Tom's Hardware
Games

Studios Pull Playtests Over Clone Fears

Game Developer notes that Digital Sun Games canceled a public playtest of ReVamp and Moonlighter's developer delayed one, both worried a demo could be fed into an AI tool. Developers have also pressed Valve about cloned games on Steam.

The outlet adds that the rule may only stop low-effort copycats, and that it is unclear how software could tell who owns a game idea.

🧠 Analysis
Take

Prompt-Level Guardrails Are a Blunt Tool

Two sentences in a system prompt now shape what millions of devs can build. That is fast and cheap for Anthropic, but it is hard to aim. The people complaining are hobbyists, modders and security folks, not the copycats.

With an IPO roadshow possibly 8 days out, expect more of these calls and more scrutiny of how they get made. If your workflow touches games or reverse engineering, test it now and plan a fallback.
