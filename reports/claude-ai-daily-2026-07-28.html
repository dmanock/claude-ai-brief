🚀 Official Updates
Product

The Anthropic Economic Index Connector Puts AI Jobs Data Inside Claude

Anthropic launched a connector for the Anthropic Economic Index, its public dataset measuring how AI is actually used across the economy. Turn it on and you can ask Claude plain-language questions — which occupations use AI the most, what tasks teachers automate, the most common use cases in a given state — with answers grounded directly in the Index rather than the model’s guesswork.

Setup is a one-click enable inside the connectors directory, no install, and it works in any conversation on any model. The current data still skews toward software development and technical writing, but over a third of occupations now show AI use in at least a quarter of their tasks — and now that number is queryable in chat.

Product

Claude Cowork Expands to Mobile and Web — With Doubled Limits

Claude Cowork, the agent that runs multi-step file-and-task work, is now in beta on the web and the Claude mobile apps for Max subscribers, alongside the desktop app. The headline capability: tasks run in the cloud even when no device is online, and Claude pings you for approval when it hits a step that needs a decision.

To encourage people to push it harder, Anthropic doubled the five-hour Cowork usage limits through August 5 for eligible Pro, Max, Team, and legacy Enterprise seats. The rollout is staged — Max first, other tiers in the coming weeks — effectively turning your phone into a remote control for background AI work.

API

Mid-Conversation Tool Changes and Default Fallbacks Hit Beta

Two useful additions on the Claude Developer Platform. First, mid-conversation tool changes (beta): you can now add or remove tools between turns of a conversation while preserving the prompt cache — so an agent can gain or drop capabilities mid-flow without paying to re-warm the context.

Second, the fallbacks parameter gains a “default” mode that applies Anthropic’s recommended backup models by refusal category, instead of making you hand-pick fallbacks yourself. Together they make long-running agent sessions cheaper to adapt and more resilient when a primary model declines a request.

Claude Code

Agent Memory Gets a Stable Order; Claude Code Ships More Polish

The new agent-memory-2026-07-22 beta header makes memory listings return a stable, server-defined order and tightens depth and cursor behaviors — a small but meaningful fix for anyone building agents that read and write persistent memory and need deterministic results.

On the CLI side, recent Claude Code releases added emoji shortcode autocomplete, clearer transcript-write warnings, and a fix for a memory leak where truncated MCP outputs held the full result all session, plus improvements to resume flows, telemetry settings, and Windows stability.

Opus 5 Momentum Feeds the IPO Story

The backdrop to all of it: Claude Opus 5, launched July 24 at roughly half of Fable 5’s price ($5 / $25 per million tokens) and now the default on Max, keeps drawing developers as Anthropic meets investors ahead of a possible fall IPO under ticker ANTH. 🧠 Analysis
Take

Anthropic Is Quietly Building the Utility Layer

Zoom out from today’s individual items — an Economic Index connector, Cowork running in the cloud from your phone, mid-conversation tools in the API, HIPAA config for Enterprise — and they rhyme. None of them is a new frontier model. All of them make Claude easier to leave running inside a workflow. Anthropic already has the capability story; this week is about the surface area around it.

That’s the smart move heading into an IPO. Raw model benchmarks are volatile and easily matched; connectors, cloud agents, compliance controls, and sticky developer plumbing are the things that compound into switching costs. If you’re building on Claude, plan for a world where the model is a commodity and the integration is the moat — and notice that Anthropic is building that moat in public, one unglamorous release at a time.
