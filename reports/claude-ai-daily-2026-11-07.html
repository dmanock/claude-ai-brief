Anthropic's Public S-1 Puts Numbers on the Table

Anthropic filed its public Form S-1 with the SEC on Oct. 26, after a confidential draft on June 1. Per a German outlet's read of the filing, it plans to list Class A shares as ANT on the Nasdaq Global Select Market. No price range is out yet.

The reported figures: about $16.3B in revenue for H1 2026, up from $1.16B a year earlier, with the operating loss narrowing to about $693M. Reported compute commitments run roughly $517B. Trading could start before Thanksgiving (Nov. 26), but that timing is unconfirmed. Bloomberg reported on Oct. 1 that marketing could begin the week of Nov. 9.

Claude Code

Claude Code Loosens the Game-Cloning Rule

Anthropic updated the rule in Claude Code 2.1.317. Per Tom's Hardware, users can now name a game to describe the mechanics they want, and Claude should build an original game in that genre. If someone explicitly asks for a copy, Claude offers to build something similar instead.

The original rule, added to the Opus 5.5 prompt, also fired when people only named a game as a reference. The report relays this from an X post by Anthropic's Addy Osmani, so check Anthropic's docs for the exact wording.

Console IP Allowlist and Admin API Member Sign-Out

Two release-note entries landed Nov. 5. The Console now has an IP allowlist (beta) for organizations, supporting up to 1,000 IPv4/IPv6 addresses or CIDR ranges. The Admin API can also sign a Claude Enterprise member out of Claude everywhere (beta).

Handy for security teams. Pair them with last week's Enterprise security center.
