Headline

Cowork Goes Cloud, Mobile & Web — and 90% of It Isn’t Coding

Anthropic moved Claude Cowork off the desktop and into the cloud, turning a single-device agent into a cross-device platform. A task can start on a laptop, continue autonomously in the background, and be reviewed from a phone even after the app is closed — sessions run remotely, files and state save to your Claude account, and scheduled tasks can complete with no device online. Beta access starts with Max subscribers and widens over the coming weeks.

The bigger story is the data Anthropic published alongside it. Across 1.2 million anonymized sessions from more than 600,000 organizations, software development was just 8.7%. Business operations led at 33.4% and content creation at 16.4% — the “work around the work.” The coding-agent wars, it turns out, are spilling into the rest of the office.

Claude for Government Enters Public Beta on FedRAMP High

Anthropic opened a public beta of Claude Code and Claude Cowork inside Claude for Government Desktop, bringing FedRAMP High authorized AI to public-sector teams. It pairs desktop, file-based agent work with the controls agencies actually need: stronger admin controls, tamper-evident audit logs, and spend governance to keep autonomous runs on a leash.

The commercial angle matters too. Anthropic remains the contracted and billing party, so agencies don’t need a separate cloud-provider relationship to get started — a meaningful simplification for government procurement. New customers can request access at claude.com/solutions/government.

Platform

API Key Expiration Arrives; Rate Limits Jump and Tiers Consolidate

The Claude Developer Platform shipped a security-minded quality-of-life win: you can now set an expiration when you create an API key or Admin API key in the Console — a preset, a custom duration, or Never — with Anthropic emailing the creator before expiry on any key that lives at least 7 days. Overdue, and welcome.

On capacity, rate limits went up across the board: Claude Sonnet and Claude Haiku now match Claude Opus at every usage tier, and the old ladder of tiers has been consolidated into three — Start, Build, and Scale. Simpler mental model, more headroom for anyone scaling agent workloads.

Deprecations

Mark Your Calendar: Opus 4.1 Retires Aug 5, Opus 4.7 Fast Mode Goes July 24

Two deprecation clocks are ticking. Claude Opus 4.1 (claude-opus-4-1-20250805) is deprecated with retirement on the Claude API scheduled for August 5, 2026. And fast mode for Claude Opus 4.7 is deprecated with removal on July 24 — after that, requests to claude-opus-4-7 with speed: "fast" will return an error.

If you have production traffic pinned to either, now is the window to migrate and test. The pace of model turnover is a reminder to keep version strings in config, not hard-coded across your stack.

Integration

Microsoft 365 Write Tools: Claude Can Now Send Your Email

The Microsoft 365 connector crossed from reading to writing. With write tools enabled, Claude can draft, send, and organize email, manage calendar events, update mailbox settings, and create and update files in OneDrive and SharePoint. Read and search tools work as before, and Teams remains read-only.

The guardrails are front-loaded: before anyone can use write tools, a Microsoft Entra administrator must consent to the updated permission set and an admin has to enable them for the org. Rollout is Max-first over the next several weeks. Handing an agent the power to actually send mail is a real capability jump — and a real reason to think hard about approvals.

Take

The Work Around the Work

Anthropic just told on itself in the best way. When you ship usage data showing 91% of your flagship agent’s sessions have nothing to do with coding — business ops at a third, content creation at a sixth — you’re not describing a developer tool anymore. You’re describing an assistant for the whole knowledge-worker economy, and you’re quietly repositioning the entire company around it.

Line up today’s moves and the strategy is obvious: Cowork goes cloud so the work follows you across devices, Microsoft 365 write tools put Claude where the ops work already happens, and Claude for Government drags the whole thing into the most procurement-heavy market on earth. The coding-agent wars grabbed the headlines and the developer mindshare. But the land Anthropic is actually annexing is everything that happens around the code — the emails, the calendars, the SharePoint files, the “can you just handle this” tasks that fill a workday. That’s a far bigger map.
