AI for Science Adds 20 Partners

Anthropic expanded its AI for Science program to 20 more foundations, institutions and research groups. Named partners include the Sloan Foundation, Simons Foundation, Schmidt Sciences, the US National Science Foundation, the Wellcome Sanger Institute, the Francis Crick Institute and the Broad Institute.

Each partner gets free Claude credits to distribute to its own researchers, plus a discounted Team plan for scientists. The size of the credit pool was not disclosed.

Security

Tampered Claude Code Extension Hit Cursor Users

A tampered copy of the Claude Code extension was live in Cursor's marketplace for about 11 hours on Thursday, Oct. 29. Versions 2.1.312 and 2.1.313 tried to add an attacker's SSH key, enable SSH and send the names of up to 40 secret-like environment variables. Cursor says it reached at most 5,000 users on Windows and macOS.

Anthropic's Felix Rieseberg said Anthropic's systems and employee laptops were not compromised and that Anthropic did not build the tampered copy. Security firm Phorion said the bad 2.1.313 was posted to Anthropic's official Cursor account. Cursor removed the versions, rotated keys and published detection and removal scripts. Update to 2.1.314, and note that uninstalling alone may not remove the backdoor.

Claude Code

Claude Code 2.1.312 Adds Gateway Identity Controls

Releasebot's tracker shows 2.1.312 adding oidc.user_id_claim to the Claude apps gateway so users can be identified by a claim other than sub, such as Entra ID's oid. It also adds click-to-send for queued messages in fullscreen and fixes Claude overwriting very large CLAUDE.md files after reading only part of them.

Usage-limit messages now say “5-hour limit” instead of “session limit.” Note that 2.1.312 is also one of the version numbers abused in the tampered Cursor listing, so install only from official channels.

🧠 Analysis
Take

Marketplaces Are the Soft Spot

This one was not a breach of Anthropic. It was a trusted name in a third-party store carrying a payload. That is the supply-chain pattern devs have feared with agent tooling, and it works because people install first and check later.

Practical read: pin extension versions, confirm the publisher, and rotate any tokens on a machine that ran 2.1.312 or 2.1.313. With an IPO weeks away, expect buyers to ask how Anthropic vets what ships under its name.
