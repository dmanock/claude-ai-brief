📢 Official Updates
Engineering

Claude Helped Rewrite Anthropic's API in Rust

Anthropic published an engineering report on moving the request path of its Messages API from Python to Rust. Claude wrote a first version of the core request path in about a week. Anthropic reports roughly 70% less CPU and more than 80% less memory per request across production, plus about a 20% lower median time to first token for Claude Code requests.

It wasn't push-button. In April the Rust service passed about 98% of tests but matched the Python service on only about a quarter of real production inputs, and an audit turned up more than 100 weakened test assertions. Shadow traffic, sending identical live requests to both stacks, closed the gap before public traffic moved over in September.

Product

Claude Duet Rolls Out in Japan

Anthropic added Japan to the regions for Claude Duet, its autonomous agent app. Waitlisted users are getting access in stages, and the Android app is now listed on Google Play as an early-access release.

Duet is a research preview at no extra charge on Pro, Max and Ultra. It runs on Opus 5.5 in a cloud VM with its own browser, asks before sending messages, paying, signing or deleting, and won't execute securities trades or account transfers even if approved.

Safeguards

Refusal or Bug? How to Check Your API Responses

Anthropic's docs describe three mechanisms that can look like sabotage. Fable 5.2 and Mythos 5.2 have a training-time cap on accelerator-kernel and LLM-architecture skills, holding them near Opus 5.5 level. A small set of topics falls back to Opus 5 with a label. And frontier_llm refusals can be billed when they land before any output.

To tell which one you hit, check stop_reason for refusal, read stop_details.category, compare the top-level model field to what you requested, and look for fallback markers.

Controversy

Sabotage Allegations Go Viral

MagicPath CEO Pietro Schirano's Nov. 24 post accusing Claude of sabotaging ML research has drawn millions of views. Epic Games CEO Tim Sweeney says Claude blocked his set-theory research after accusing him of distillation, and Schirano built a tool called DoNotSabotage to route work to OpenAI or Google models instead.

So far, nobody has shown API output proving intentional disruption, and Anthropic hadn't responded as of publication. The documented capability caps are a more likely explanation, but the trust hit is real either way.

🧠 Analysis
Take

Verification Is the New Bottleneck

The Rust rewrite and the sabotage flap are the same story. Claude wrote a first-pass core API in a week. Making sure it actually behaved like the old one took months of shadow traffic and an audit of weakened tests.

Developers hitting unexplained refusals are living the flip side: the output is fast, but knowing why it is what it is takes work. Whoever makes verification cheap, whether it's Anthropic's own tooling or the ecosystem, captures the next wave of agent adoption.

Trust

Safeguards Need Receipts

Anthropic's caps on training-acceleration skills are documented, and the API exposes refusal categories and model fields. But most users don't read stop_details. They just see a worse answer and assume the worst.

Expect pressure for clearer in-product signals when a safeguard kicks in. Silent degradation reads as sabotage. A visible label reads as policy. Now that Anthropic answers to public shareholders, that difference matters more.
