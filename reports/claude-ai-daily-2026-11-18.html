Pricing Night: Anthropic Sets Its IPO Price Today

Anthropic sets the final price on its Nasdaq IPO tonight, with ANT due to start trading Thursday at 9:30 a.m. ET. The range is $70 to $78 on 825M shares, which works out to about $64B raised and a valuation of up to roughly $1.4T at the top.

Demand looks hot. Bloomberg reported orders near 7x the shares on offer, and the WSJ said the price could clear $80, implying $1.5T to $1.6T. On top of the IPO, a $26B private placement from AMD, Broadcom, Google, Micron, Microsoft, Nvidia and TSMC comes in at the IPO price, and CNBC reports Altimeter’s Brad Gerstner committed $5B.

Models

Mythos Preview Ported AMD GPU Kernels in Three Days

Anthropic told IPO investors that Claude Mythos Preview ported nearly all the kernels needed to run one of its models on AMD MI355X GPUs in about three days, with basically no human intervention, per Tom’s Hardware.

Chief compute officer Tom Brown said that work used to take dozens of engineers six to 12 months. If it holds up, it is a big deal for Anthropic’s chip leverage: less lock-in to any one hardware vendor.

Security Policy

Anthropic Cuts Bug Disclosure Window to 30 Days

Anthropic shortened its coordinated vulnerability disclosure window for high-severity bugs from 90 days to 30. Vendors notified of serious flaws now get a month, not a quarter, before details go public.

It fits the moment. When models like Mythos can find bugs at machine speed, a 90-day clock starts to look slow.

API

Text Watermarking Extends to Older Claude Models

Per the Developer Platform release notes, output from Claude Opus 4.6, Opus 4.5, Sonnet 4.5 and Haiku 4.5 now carries Anthropic’s text watermark on supported platforms.

One gotcha: requests that set temperature, top_p or top_k to non-default values may not carry the watermark. Worth knowing if you rely on it for provenance.

Claude Code

Claude Code Adds an Experimental Code Mode

Version 2.1.323 adds Code Mode, an opt-in experiment where Claude writes JavaScript to call its tools instead of making calls one by one. It is off by default. The release also adds an engines["claude-code"] version field for plugins and warns on risky wildcard Bash allow rules.

2.1.325 followed with a security fix for zstd-compressed response decoding, plus fixes for long sessions on third-party gateways and resumed sessions dropping recent turns. Versions 2.1.326 and 2.1.327 have shipped since. Update if you haven’t.

Rate Limits

New API ‘Ramp Limits’ Can 429 Bursty Traffic

Anthropic’s API docs now define ramp limits, which cap how fast token usage can climb. Spiky workloads can hit HTTP 429s even while under per-minute caps. If you fan out big batch jobs, warm up gradually and keep retry backoff in place.

Security

Backdoored Claude Code Extension Hit About 5,000 Devs

Cursor confirmed a leaked Fireworks AI key let attackers ship a malicious Claude Code extension to about 5,000 developers, per BleepingComputer. Anthropic itself was not breached. If you installed a Claude Code extension through a third-party marketplace recently, check it and rotate any keys it could see.

Take

The Price Is the Easy Part

Tonight’s number will probably land at or above the top of the range. The real test is what happens after: slowing growth and nearly a trillion in compute bills on one side, Mythos porting GPU kernels in three days on the other.

That kernel story is the pitch in a nutshell. An AI that cuts its own maker’s compute costs and vendor lock-in is the bull case for $1.4T. A model that can do that can also find bugs fast, which is why the 30-day disclosure window landed the same week.
