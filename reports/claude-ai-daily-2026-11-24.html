Launch

Claude Ship: Agents That Review, Fix and Approve Your PRs

Anthropic launched Claude Ship, a set of Claude Code-based agents that cover the pull request from review to approval. It bundles Code Review (now generally available) with two beta agents: PR Steward, which fixes failing CI checks, merge conflicts and review feedback and comments after every push with how to roll it back, and Claude Approvals, which approves changes that pass a policy your team writes as a file in the repo.

It's for Team and Enterprise plans on GitHub repos, billed on token usage, with Quick, Standard and Deep review levels and monthly spend caps. Anthropic suggests running approvals in observe-only mode first. Not available with Zero Data Retention, HIPAA configs or customer-managed keys. Eligible Enterprise orgs can claim at least $10,000 in credits by Jan. 15, 2027. Anthropic says merged PRs on its own Claude Code team more than doubled from June to September while reverts fell over 40%.

Enterprise Frontier Safeguards Now Works With Zero Data Retention

Per a Nov. 23 entry on Releasebot's Claude feed, Enterprise Frontier Safeguards (EFS) is now in public beta with zero data retention. EFS runs automated misuse monitoring while data stays in customer-controlled storage.

It's available on Claude Platform, Claude Platform on AWS, Amazon Bedrock and Google Cloud, with Microsoft Foundry support coming soon. Bridgewater, Salesforce and Stripe are named as early evaluators. Worth noting for regulated shops: Claude Ship doesn't support ZDR orgs yet.

Claude Code

Claude Code 2.1.331 Brings Code Mode to the Clouds

Version 2.1.331 shipped late Nov. 23 (UTC). Code Mode now works in terminal sessions on Amazon Bedrock, Google Cloud's Agent Platform, Microsoft Foundry and Claude Platform on AWS. claude doctor gains an API connectivity section, and plugin manifests can now declare optionalDependencies.

Fixes worth knowing: MCP tool calls that could hang up to 30 minutes on some malformed replies, Stop hooks in Claude Desktop missing the last reply, and turns that failed when a reply went silent (Claude Code now retries once). New env vars include CLAUDE_CODE_DISABLE_RESPONSE_COMPRESSION and CLAUDE_GATEWAY_IDP_CONNECT_BY_HOSTNAME=1.

Heads-Up

Managed Plugin Marketplaces Will Auto-Update After Nov. 30

Tucked into the 2.1.331 notes: starting with a release on or after Nov. 30, managed extraKnownMarketplaces plugin marketplaces will auto-update by default.

If your org pins plugin versions on purpose, set "autoUpdate": false in managed settings before then. The release also changes how PermissionDenied hooks handle retry: true, so check any custom hooks.

A Claude-Authored VP ≠ VNP Proof Lands, Unchecked

Anthropic posted a GitHub paper credited to "Claude (Anthropic)" as sole author, claiming Valiant's VP ≠ VNP conjecture over every field, with a Lean 4 formalization. The repo's README says plainly that no human mathematician has checked the proof, and that it does not settle P vs NP.

AI Weekly reports the roughly 70-page paper's Lean code passed automated checks, but notes that doesn't prove the formal statements match the paper. It follows last week's Claude-assisted Riemann claim. Treat it as a big claim waiting for complexity theorists, not a result.

🧠 Analysis
Agents

The Approve Button Is the New Frontier

Code review bots aren't new. Letting the bot hit approve is. Claude Ship's pitch is that the bottleneck in AI-assisted coding moved from writing code to reviewing it, and the only way through is policy-based auto-approval.

Anthropic is careful here: observe-only mode, policies as files in the repo, escalation rules, spend caps. But the direction is clear. The human moves from reviewer to policy author. Expect GitHub, Cursor and OpenAI to answer fast.

Take

Proofs Without Reviewers

Riemann last week, VP ≠ VNP this week. Claude is producing math faster than humans can check it, and Lean is carrying the load as the referee.

That's the same pattern as Claude Ship, just in a different field: AI writes, machines verify, humans set the rules. Whether that's trustworthy depends on one thing nobody has fully solved yet. Making sure the spec says what you think it says.
