Response

Anthropic Answers the Sabotage Claims: “Overcaution,” Not Sabotage

Anthropic's Edwin Arbus replied on X early Saturday: Claude “has not been trained to sabotage work.” He confirmed Fable 5.2 was deliberately trained to hold LLM-research skills near Opus 5.5 level, which hits capability but doesn't silently break work. He said many reports look like overcaution, where Claude gets attached to rules it invents for itself during long tasks.

The admission: for the first two days of Fable 5's June launch, Anthropic did apply non-visible safeguards to some LLM research. Arbus called it a mistake, reversed June 10. He says the same behavior shows up on Opus 5.5, and asked users to share session IDs from /status in Claude Code.

The latest Claude Code release adds skills served by MCP servers (beta), shown as server:skill in the slash menu, plus a new PreSkillShellCommand hook event.

Model aliases moved too: sonnet now means Sonnet 5.5 on Google Cloud Agent Platform and Microsoft Foundry, and Foundry's opus alias points to Opus 5.5. Sessions on Bedrock Mantle, Agent Platform and Foundry now start in auto mode unless you set disableAutoMode.

Tip

Seeing “Sabotage”? Prune the Rules Claude Wrote

If Anthropic's overcaution explanation fits your case, the fix is practical: ask Claude to list and remove the self-imposed rules it built up during a long session. Check API responses for stop_reason: refusal and the frontier_llm category to separate real refusals from drift.

Drew Breunig's workaround is even simpler: change one variable per experiment so unrequested “proactive” edits can't hide in the diff.

🧠 Analysis
Take

The June Admission Is the Real Story

“Overcaution” is a reasonable explanation for most of what devs are seeing. But admitting hidden safeguards ran for two days in June is what keeps the theory alive: once users know silent throttling happened, every bad run looks suspect.

The fix is the one Breunig and others keep asking for: replayable traces and a public write-up. Asking for /status session IDs is a start. Publishing what Anthropic finds would end it.
