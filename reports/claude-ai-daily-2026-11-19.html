Company

Anthropic Prices at $83, Raising a Record $81.3 Billion

Anthropic priced its IPO at $83 a share Wednesday night, above the $70 to $78 range, selling 980 million Class A shares: about 956 million from the company and 23.6 million from existing holders. That's roughly $81.3 billion, the largest IPO on record, ahead of SpaceX's $75 billion, at a valuation reported near $1.5 trillion.

Shares trade on the Nasdaq Global Select Market as ANT starting today, with the deal expected to close Friday, Nov. 20. Goldman Sachs and Morgan Stanley lead, and underwriters hold a 30-day option on up to 147 million more shares.

Platform

Linked Billing Arrives on Claude Platform in Beta

Claude Platform customers can now link their organization so third-party apps bill Claude usage to it, without anyone sharing an API key. Admins set spend caps or unlink an app from the Console.

On the API side, a new beta header and a billing_policy field on /v1/messages and /v1/chat/completions decide who pays for a request. It's a cleaner path for SaaS tools that want to run on a customer's own Claude contract.

Apps

Claude Desktop Adds Stable and Latest Release Channels

Claude Desktop users can now choose a release channel. Stable stays the default, with less frequent, more tested updates, while Latest ships roughly daily builds.

If you want new features the day they land, switch to Latest. If the app is part of your daily workflow and you value predictability, leave it on Stable.

Claude Code

Claude Code 2.1.328 Starts in Auto Mode on Cloud Providers

Interactive sessions with no permission mode set now start in auto mode for Opus 4.6 and Sonnet 4.6 on Amazon Bedrock, Google Cloud's Agent Platform, Microsoft Foundry and the Claude apps gateway. That brings cloud-provider users in line with the default first-party experience.

MCP tool hooks also gain an onFailure: block option, so a failed hook can stop a tool call instead of letting it through. And saving a scheduled task no longer wipes other saved tasks when the tasks file can't be read.

Claude Code

Safety Fixes in 2.1.326 and 2.1.327: Update Now

Version 2.1.327 fixes a nasty one: stopping the Remote Control server in worktree mode could delete git-ignored files such as .env. It also keeps other top-level keys intact in .mcp.json and adds a /status list of broken agents, skills, commands and hooks.

Version 2.1.326 hardens the sandbox so commands on macOS, Linux and WSL no longer write to some sensitive home folders by default, and file tools refuse writes to sign-in files like .credentials.json. Code Mode now also works with agent teams enabled.

Crypto

Tokenized ANT Goes Live on BNB Chain on Day One

Changpeng Zhao said tokenized ANT would be live on BNB Chain from the first day of trading via bStocks, Ondo and xStocks. Binance Wallet's 500 million USDC Anthropic subscription cap reportedly filled early.

The tokens track the stock but carry no shareholder rights, so holders get price exposure without votes or the legal standing of real shares. Expect more of these wrappers around big listings.

Options Could List as Soon as Monday

Reuters reports ANT options could start trading as soon as Monday, Nov. 23, with Cboe expecting to list them two business days after the stock begins trading. Options plus a record-size float means price discovery will move fast.

Add the fast-track index talk and the tokenized versions overseas, and ANT will be one of the most actively traded names on the board within a week of listing.

Take

The Ticker Is the Headline. Distribution Is the Story.

Today the market finally puts a live price on Claude. But look at what shipped this week: linked billing lets any app run on a customer's Claude contract, and auto mode by default removes friction for enterprise cloud users.

Both are about getting Claude into more places with fewer obstacles. That distribution engine, not the opening print, is what a $1.5 trillion valuation has to keep earning.
