Compliance

Self-Serve HIPAA Configuration Arrives for Enterprise and API Orgs

Anthropic added self-serve HIPAA configuration for both Claude Enterprise and the Claude Platform. Eligible orgs can review and accept a Business Associate Agreement, download an implementation guide, and enable HIPAA support in a single step — turning what used to be a sales-led, weeks-long process into a few clicks.

For healthcare, life sciences, and any team touching protected health information, this lowers the bar to getting Claude into a compliant workflow. It also fits a pattern: Anthropic keeps productizing the paperwork that regulated buyers need, so procurement stops being the reason a deployment stalls.

Product

Cowork on Mobile and Web Keeps Widening Its Rollout

Claude Cowork — the agent that works directly with your files and runs tasks in the background — is continuing to roll out beyond its initial Max-subscriber launch on iOS, Android, and the web. Start a task at your desk, check status on your phone, and pick up the finished output later, even with the laptop closed.

Deprecation

Fast Mode for Opus 4.7 Is Removed Today — Migrate to 4.8

Mark the date: as of July 24, fast mode for Claude Opus 4.7 is gone. Any request sent with speed: "fast" to 4.7 now returns an error rather than degrading gracefully, so anything still pointed at the old model needs to move.

The fix is a one-line swap: send fast-mode traffic to Claude Opus 4.8 instead. If you run scheduled jobs or agents you don’t watch daily, this is the kind of quiet break that surfaces as a 4xx in your logs — worth a grep through your model configs before the weekend.

Rate Limits

Four Usage Tiers Become Three, and Every Limit Goes Up

Anthropic consolidated its four usage tiers into three — Start, Build, and Scale — and raised RPM, ITPM, and OTPM limits at every level. Notably, Sonnet and Haiku now carry the same limits as Opus within each tier, so picking a cheaper model no longer costs you throughput.

The other quiet win: cache-read tokens no longer count toward your ITPM on any current model. If you lean on prompt caching, your effective input headroom just went up without you touching a thing — a real gift for high-volume agent workloads.

Security

API Keys Can Now Carry Expiration Dates

The Claude Console now lets you set an expiration when you create an API key — preset durations, a custom length, or Never. Anthropic emails the key’s creator 7 days before expiry (for keys with at least a 14-day life) and again 1 day before (for keys living at least 7 days), so rotations stop being a surprise.

It’s a small setting with outsized security value. Short-lived keys for contractors, CI jobs, and experiments mean a leaked credential has a shelf life — exactly the hygiene that security reviewers ask about before signing off on a platform.

Deprecation

Legacy Workbench and Prompt Tools APIs Retire August 17

Anthropic is winding down the legacy Workbench and experimental prompt tools APIs, with access ending August 17, 2026. Teams still calling those endpoints have a few weeks to move off them before they go dark.

Paired with today’s fast-mode removal, the signal is clear: the platform is pruning its older, experimental surface area to keep the supported path clean. Good discipline for Anthropic, a to-do item for anyone who wired up the early tooling and forgot about it.

Research

Interpretability Team Finds an “Emergent Mental Workspace” in Claude

Anthropic’s interpretability researchers described an emergent internal workspace in Claude — a “J-space” that holds intermediate thoughts which never appear in the model’s visible output. The work is part of the team’s broader effort to map how large models actually reason on the inside.

It’s early, and the framing has drawn its share of debate about how far the human-cognition analogy should stretch. But the practical stakes are real: understanding where a model “thinks” before it speaks is foundational to catching misalignment before it reaches the user.

🧠 Analysis
Take

A Maintenance Day, and That’s the Point

No new model dropped today. Instead: a fast-mode sunset, a tier reshuffle, key expiration, an API retirement date, self-serve HIPAA, a services JV, a 50,000-seat partner deal. Read as a list it looks like housekeeping. Read as a strategy, it’s the unglamorous infrastructure a platform builds when it expects to be load-bearing for a very long time.

This is what maturing looks like. Simpler tiers and higher limits make the economics predictable. Expiring keys and self-serve compliance make the security reviewers say yes. Ode and TCS make the deployment actually happen. The frontier-model headlines get the attention, but days like this — where Anthropic prunes dead surface area and smooths the path for careful buyers — are where a lab quietly turns into a platform people can’t easily leave.
